Một VM Alpine, một vsock, vậy thôi

Docker socket được nối qua vsock. Các port publish ra được tự động ánh xạ về localhost. $HOME được chia sẻ qua virtiofs nên bind mount dùng được ngay.

Tính năng

Đủ mọi thứ bạn cần, không thừa thứ gì

🐳

Docker engine thật

dockerd upstream chạy trong Alpine. docker, docker compose và buildx đều chạy được — thông qua context dockz.

🖥️

Dashboard native

Container, image, volume, network, registry, compose stack. Form tạo / sửa, log trực tiếp, inspect, cùng bộ lọc + tìm kiếm trên mọi danh sách (container nhóm theo stack, container crash được đánh dấu) — giống Docker Desktop, nhưng viết bằng SwiftUI.

📦

Máy ảo Linux

VM Alpine / Debian / Ubuntu (ARM64), truy cập qua SSH. Template cluster k3s / k8s master + node chỉ với một click. Kiểu Multipass, dùng chung một mạng NAT.

🚀

Thiết lập trong một cửa sổ

Lần chạy đầu tiên, DockZ build guest image trong một VM netboot dùng xong bỏ, đồng thời tải CLI song song. Đóng cửa sổ lại là docker ps chạy được ngay.

🔌

Tự động forward port

Các port TCP và UDP được publish sẽ tự động ánh xạ về localhost thông qua Docker events API. Không cần cấu hình gì.

📸

Snapshot VM

Snapshot copy-on-write APFS tức thì cho ổ đĩa VM, có rollback. Dùng Rosetta để chạy image linux/amd64 trên ARM.

⚙️

Tùy chỉnh được

Số CPU, RAM, giới hạn ổ đĩa, chia sẻ $HOME qua virtiofs, thư mục dữ liệu đổi được vị trí (chuyển toàn bộ sang SSD rời).

🧰

Docker CLI khi cần

Không cần Homebrew. DockZ tải binary tĩnh chính thức của docker + compose, có kiểm checksum, rồi nối vào terminal của bạn bằng một đoạn trong ~/.zshrc có thể gỡ bỏ.

🪶

Tối thiểu phụ thuộc

Chỉ gồm framework của Apple, code trong repo này, và swift-nio-ssl của chính Apple (đã pin phiên bản) cho TLS key lưu bằng phần cứng. Build được chỉ với Command Line Tools.

🌐

Nhiều môi trường

Quản lý Docker host từ xa qua SSH hoặc mutual TLS — hoặc Colima / OrbStack ngay trên Mac này — và chuyển mọi tab bằng ⌘1…⌘9. TLS key nằm trong Secure Enclave, mở bằng Touch ID.

📊

Monitor

CPU, bộ nhớ, mạng và ổ đĩa của từng container theo thời gian thực, cùng các chỉ số của VM, phân tích dung lượng lưu trữ, và dọn image, volume, build cache không dùng chỉ với một click.

🛟

VM tự phục hồi

Nếu engine ngừng phản hồi hoặc kernel của guest gặp lỗi, DockZ tự khởi động lại VM và giữ console log của các lần boot gần đây để chẩn đoán.

Cài đặt

Tải về, hoặc tự build chỉ với một lệnh

macOS 15+ trên Apple Silicon. Không cần Homebrew (nhưng vẫn có bản Homebrew), không cần mật khẩu admin.

1. Tải về

Tải DockZ-<version>.dmg từ trang Releases, kéo DockZ vào Applications rồi mở lên. Với bản build chưa notarize: cho phép một lần trong System Settings → Privacy & Security → Open Anyway.

# hoặc cài bằng Homebrew brew tap nextage-soft/dockz https://github.com/nextage-soft/dockz brew install --cask nextage-soft/dockz/dockz

2. …hoặc build từ mã nguồn

Cần có Command Line Tools. Script tự ký kèm entitlement cho VM (dùng chứng chỉ Apple Development nếu tìm thấy, không thì ký ad-hoc). Muốn dùng chứng chỉ riêng? Xem hướng dẫn ký.

git clone https://github.com/nextage-soft/dockz.git cd dockz scripts/build-and-bundle-app.sh open build/DockZ.app

3. Dùng docker như bình thường

DockZ tự tải CLI và thiết lập context dockz giúp bạn.

docker run --rm hello-world docker run --rm -p 8080:80 nginx # mở http://localhost:8080 — chạy luôn

4. (Tùy chọn) Máy ảo Linux

Tạo một VM Ubuntu và SSH thẳng vào từ Terminal.

# Trong dashboard: Machines → New → Ubuntu 24.04 ssh ubuntu@<ip> docker context use dockz
FAQ

Câu hỏi thường gặp

Đang cân nhắc giữa các công cụ? Xem so sánh DockZ với Docker Desktop, OrbStack và Colima.

DockZ có phải là lựa chọn miễn phí thay Docker Desktop trên Mac không?

Đúng vậy — miễn phí, giấy phép Apache 2.0, công ty dùng cũng không phải mua license theo đầu người. DockZ chạy Docker Engine thật (dockerd) trong một VM Alpine Linux gọn nhẹ trên Virtualization.framework của Apple.

DockZ khác gì OrbStack hay Colima?

OrbStack rất tốt nhưng là mã nguồn đóng và phải trả phí khi dùng cho mục đích thương mại; Colima miễn phí nhưng chỉ có CLI và cài qua Homebrew. DockZ là app native mã nguồn mở hoàn toàn, chỉ ~8 MB, có dashboard GUI, không cần Homebrew, không cần mật khẩu admin, và còn quản lý được cả máy ảo Linux đa dụng.

Chạy Kubernetes (k3s/k8s) trên DockZ được không?

Được — tab Machines tạo VM Alpine/Debian/Ubuntu kèm template master/node k3s hoặc kubeadm chỉ với một cú click; các node dùng chung một mạng NAT nên bạn dựng được cluster nhiều node ngay trên một chiếc Mac.

docker compose / buildx / amd64 có chạy được không?

Có. Engine là Docker upstream nên compose, buildx và registry riêng chạy y hệt như trên Linux. Image linux/amd64 chạy qua Rosetta.

DockZ có quản lý được Docker host từ xa không?

Có — bạn thêm các engine khác qua SSH hoặc mutual TLS (hoặc socket của một engine khác ngay trên Mac) rồi chuyển qua lại giữa chúng trên mọi tab. Client key TLS được tạo trong Secure Enclave của Mac và dùng kèm Touch ID.

Có cần cài Docker hay Homebrew trước không?

Không. Lần chạy đầu tiên, DockZ tự build guest image và tải docker CLI chính thức + plugin compose, có kiểm checksum — một chiếc Mac mới tinh đi từ con số 0 tới docker ps chỉ trong một cửa sổ.

Sẵn sàng tạm biệt Docker Desktop?

Tải về (hoặc build trong vài phút), gỡ Docker Desktop và quên luôn Electron đi. DockZ chạy native, tốn rất ít RAM và không gửi dữ liệu về cho ai cả.
